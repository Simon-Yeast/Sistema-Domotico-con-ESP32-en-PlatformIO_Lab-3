# Sistema-Domotico-con-ESP32-en-PlatformIO_Lab-3
Sistema embebido domótico que controla temperatura e iluminación de una habitación con un ESP32. Integra LM35, bombilla incandescente como calefactor, motor paso a paso bipolar con puente H para ventilación, fotoresistencia y dos LEDs de potencia. Implementado en C con ESP-IDF sobre PlatformIO. Laboratorio 3, Sistemas Embebidos EIA 2026-1.
